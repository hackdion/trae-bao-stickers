# TRAE宝：原画质动态版 v5

这一版直接将原先的高清二次元效果图裁成6张，在逐帧动画中保留了原图的全部纹理、阴影、服装和构图，而不是把角色重新画成低分辨率像素图。

输出文件：
- 每张 *_原画.png：未经动画处理的高清原始单张，512×512。
- 每张 *_高清动态.webp：约2.5秒、30帧、512×512，全彩动画，优先查看此格式的画面细节。
- 每张 *_高清动态.gif：约2.5秒、30帧、512×512、采用优化调色板的GIF；由于GIF标准限制，渐变颜色仍不如WebP。
- 每张 *_动画中间帧.png：用于直接对比 GIF 与原始静帧。

重要限制：目前的动画主要通过原画局部形变、视觉镜头、动态特效实现，并不是完整的骨骼动画。要让角色真正连续地抬手、跑动或倒下而不损失质感，需要对角色进行分层重绘、绑定骨骼或使用图生视频模型生成连续角色动作，再合成GIF。
