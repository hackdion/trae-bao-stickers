# TRAE宝表情包 · 重制版

以 `../TRAE宝表情包v5/` 里六张 512×512 原画为视觉基准，重做六张**局部动作**循环动态表情。
不是把旧 GIF 改名或重新编码：动作、分层、遮罩、特效、调色、导出全部由本目录脚本重新生成。

原画来源：用户此前用 **ChatGPT** 生成并保存的 v5 原画（只读引用，未修改一个像素）。
本次新增：分层与遮罩、动作编排、特效、GIF/WebP 导出、预览页与质检脚本。

## 技术做法

1. **原画当底板，只动该动的地方。**
   拳、手、纸片、披风、像素爱心、屏幕眼睛各自提取为独立图层，其余像素保持原样，
   所以原画的纹理、阴影、服装、噪点全部保留。
2. **屏幕眼睛**用「内屏多边形 ∩ 亮度阈值 + 连通域筛选」精确提取，
   可单独做缩放、位移、变暗、发光，而不会碰到屏幕边框。
3. **只放大不挖空**：肢体/道具图层只做正向缩放（支点放在关节一侧），
   放大后的图层天然覆盖原位，不需要 inpaint，也不会出现双重轮廓或抹平色块。
4. **披风**用逐像素位移场（`cv2.remap`），位移量在披风边界衰减为 0，边缘不会裂开。
5. **节奏**用关键帧曲线 + smoothstep 缓动编排（`key_curve`），
   所有时间函数在首尾闭合，因此循环无跳帧。
6. **GIF 调色板**：每张图用整段共用的一张 255 色调色板 + **固定的**蓝噪声抖动。
   噪声不随时间变化，所以不会产生帧间闪烁；抖动只把平滑渐变的色带打散成静态颗粒。
7. 导出用 `disposal=1 + optimize=True` 只重写变化区域，体积约为整帧重写的 1/7。

对应代码：`scripts/trae_rig.py`（引擎）、`scripts/build_remaster.py`（六张的编排）。

## 复现

```bash
cd "/Users/hackdion/Desktop/TRAE宝表情包大赛/TRAE重制版"

python3 -m venv /tmp/trae_venv
/tmp/trae_venv/bin/pip install -r requirements.txt

/tmp/trae_venv/bin/python scripts/build_remaster.py          # 生成 gif/ webp/ png/
/tmp/trae_venv/bin/python scripts/verify_outputs.py          # 质检，写 检查报告.json
/tmp/trae_venv/bin/python scripts/make_previews.py           # 六宫格、新旧对照、分镜
/tmp/trae_venv/bin/python scripts/make_preview_page.py       # 生成 预览.html
```

`build_remaster.py --debug` 会额外把遮罩核对图写到 `/tmp/trae_build/debug/`；
`make_previews.py` 会把这些图复制进 `过程截图/`。
`--only 01` 可只重建某一张。

**路径要求**：脚本默认从 `../TRAE宝表情包v5/*_原画.png` 读取原画，
所以本目录必须与 `TRAE宝表情包v5/` 位于同一父目录。原画文件不会被写入。

## 能力边界（如实说明）

- **不是骨骼动画**。角色是单张原画，抬臂是“绕支点的局部放大/旋转”，
  不是关节链驱动；因此无法把整条手臂从桌面抬到头顶这类大幅换姿势。
- **02 的手部**只有小幅摆动，没有做出“手指敲下巴”的独立手指动作。
- **04 的头部**以桌面接触点为轴做压缩下沉（约 6–8px），幅度刻意压低，
  避免顶边露出修补痕迹。
- **06 的像素爱心没有做几何缩放**。它被两只深色手套夹住、背景又是同一种高饱和暖红，
  抠像后放大会在凹形边界留下重影手掌与细弧线（试了三种遮罩方案都不干净）。
  最终改为「光晕随心跳鼓起 + 描边爱心上浮 + 屏幕玻璃反光」，送心动作由向外飘的爱心承担。
- GIF 只有 256 色。第一帧之外的暗部渐变仍可能有轻微色带，
  需要最好画质请用 `webp/`。
